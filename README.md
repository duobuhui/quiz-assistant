# 小多答题助手 v0.2.1

小多答题助手是一款 Android 截图答题工具。它使用系统截图权限获取题目画面，使用本地中文 OCR 提取文字，再通过用户配置的兼容接口获得答案。应用支持悬浮窗、快速模型与深度模型、联网搜索、历史记录和可选本地题库。
## 前置声明
本软件仅通过屏幕截图和OCR功能获取APP内字段，未使用无障碍、内存读取、网络抓包等违规途径获取，也不提供自动点击、自动提交答案的功能。
希望大家明白使用无障碍自动点击、或者直接发包的软件才是真正的外挂，本软件和国内手机厂商自带的“识屏”、豆包的“屏幕共享”无异，都是更高效率的询问ai。使用上述外挂进行倒卖的黄牛才该真正抵制。后续不再发布release，有能力可以自己使用codex、gradle封包。

## 题库导入格式

导入题库只需要提供题目和答案两个字段。题库保存在应用私有目录中，不会随安装包内置。

JSON 推荐格式：

```json
[
  {
    "question": "题目文本",
    "answer": "正确答案"
  }
]
```

JSON 也可以使用：

```json
{
  "questions": [
    {
      "question": "题目文本",
      "answer": "正确答案"
    }
  ]
}
```

CSV 必须包含表头 `question,answer`：

```csv
question,answer
题目文本,正确答案
"题目中包含逗号,请使用引号","答案文本"
```

必要字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `question` | 字符串 | 题目文本或可检索的题目片段 |
| `answer` | 字符串 | 正确答案，可填写选项字母和内容 |

JSON 中可以额外保留 `id`、`question_confidence` 和 `answer_confidence`，但这些字段不是必需的。题目被截断时，建议保留具有区分度的关键词，应用会使用关键词片段进行匹配。

## 配置教程

1. 安装官方发布渠道提供的 APK，打开“小多答题助手”。
2. 在“快速回答”中选择 `dsv4flash`，或选择“自定义”后填写接口地址、密钥和模型名称。
3. 在“深度回答”中选择 `gpt5.6luna`，或选择“自定义”后填写对应配置。
4. 接口地址填写中转站提供的 OpenAI 兼容根地址，通常以 `/v1/` 结尾。应用会请求 `/chat/completions`；联网搜索模式会请求 `/responses`。
5. 只有当中转站支持 Responses 接口和 `web_search` 工具时，才打开“允许联网搜索”。
6. 设置推理强度。 `max` 适合深度模型，响应时间较长；需要更快返回时可改为 `high` 或关闭。
7. 点击“保存设置”，然后依次授权悬浮窗和屏幕截图，最后启动悬浮窗。
8. 如需使用本地题库，在“题库”区域导入 JSON 或 CSV，并打开“启用本地题库”。

快速模型用于尽快给出候选答案，深度模型用于复核和补充。启用本地题库后，命中题库会先显示本地结果，同时继续请求深度模型进行校验；深度模型判定本地答案错误时，界面会自动替换为深度答案。

## 隐私与安装安全

应用不会上传你的 API Key，也不会把密钥写入题库文件。API Key 只会随请求发送到你自己填写的接口地址。请仅通过官方发布渠道获取安装包；如果使用非官方安装包，应用可能被篡改，从而导致你的 API Key 泄露。

## 权限说明

- 悬浮窗权限：显示答题面板。
- 屏幕截图权限：通过 MediaProjection 获取截图。
- 网络权限：访问你配置的模型接口和联网搜索服务。
- 通知权限：部分 Android 版本用于显示前台截图服务状态。
